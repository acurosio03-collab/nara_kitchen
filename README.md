# ORDERIN — NARA KITCHEN FINAL

Paket ini mempertahankan file desain Stitch asli dan menambahkan koneksi/fungsi ORDERIN di lapisan JavaScript.

## Struktur
- `index.html` — desain Stitch Nara Kitchen
- `products.html` — desain menu Stitch
- `checkout.html` — desain checkout Stitch
- `order-success.html` — desain sukses Stitch
- `admin/dashboard.html` — desain Staff Performance Stitch
- `admin/analytics.html` — desain Analytics Stitch
- `admin/orders.html`, `admin/products.html`, `admin/categories.html`, `admin/settings.html` — fungsi admin lama tetap dipertahankan
- `js/supabase-config.js` + `js/supabase.js` — koneksi Supabase yang sudah digunakan
- `supabase-schema.sql` — schema yang sudah ada

Tidak ada schema/database baru di paket ini.
